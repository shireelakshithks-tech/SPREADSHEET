# Electronics Components Dataset

## Project Overview
This project contains a beginner-to-intermediate level dataset of electronic components created using Microsoft Excel.

The dataset contains 20 records with numerical and categorical features. It also includes a feature guide and multiple charts for data visualization.

## Dataset Details
- **Domain:** Electronics
- **Number of Records:** 20
- **Tool Used:** Microsoft Excel
- **Difficulty:** Beginner to Intermediate

## Features
- Component Name
- Component Category
- Voltage
- Current
- Power
- Price
- Manufacturer
- Component Type

## Visualizations
The Excel workbook includes multiple charts to understand and compare electronic component data.

## Files Included
- `Electronics_Components.xlsx` – Main dataset with charts and feature guide.

## Tools Used
- Microsoft Excel
- GitHub

## Learning Outcomes
- Understanding structured datasets
- Working with numerical and categorical data
- Creating charts in Excel
- Presenting data through visualizations
